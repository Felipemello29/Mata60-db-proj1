# Logical Model: IC Extension Management

This document defines the relational logical model for the IC Extension Management database.

## 1. Normalization Analysis
The model follows **Third Normal Form (3NF)**:
- **1NF**: All attributes are atomic. Each table has a Primary Key.
- **2NF**: All non-key attributes are fully functionally dependent on the entire Primary Key.
- **3NF**: No transitive dependencies exist (non-key attributes depend only on the Primary Key).

## 2. Relational Schema

### TB_PROJETO_EXTENSAO (Project)
- **ID_PROJETO**: INT (PK)
- **DS_NOME_PROJETO**: VARCHAR(150) NOT NULL
- **DT_CRIACAO**: DATE NOT NULL
- **ID_INSTR_COORDENADOR**: INT (FK -> TB_INSTRUTOR.ID_INSTRUTOR) NOT NULL

### TB_ATIVIDADE (Activity)
- **ID_ATIVIDADE**: INT (PK)
- **DS_TITULO_ATIVIDADE**: VARCHAR(150) NOT NULL
- **DS_CONTEUDO_PROG**: TEXT
- **DT_REALIZACAO**: DATE NOT NULL
- **ID_PROJ_VINCULADO**: INT (FK -> TB_PROJETO_EXTENSAO.ID_PROJETO) NULL

### TB_PARTICIPANTE (Participant)
- **ID_PARTICIPANTE**: INT (PK)
- **DS_NOME_PARTICIPANTE**: VARCHAR(150) NOT NULL
- **DS_EMAIL_CONTATO**: VARCHAR(100) NOT NULL
- **TP_VINCULO_INST**: VARCHAR(30) NOT NULL

### TB_INSTRUTOR (Instructor)
- **ID_INSTRUTOR**: INT (PK)
- **DS_NOME_INSTRUTOR**: VARCHAR(150) NOT NULL
- **DS_ESPECIALIDADE**: VARCHAR(100)

### TB_PARCEIRO (Partner)
- **ID_PARCEIRO**: INT (PK)
- **DS_NOME_ORGANIZACAO**: VARCHAR(150) NOT NULL
- **TP_PARCEIRO**: VARCHAR(30) NOT NULL

### TB_EMISSAO_CERTIFICADO (Certificate)
- **ID_CERTIFICADO**: INT (PK)
- **ID_INSCRICAO**: INT (FK -> RL_INSCRICAO_HISTORICO.ID_INSCRICAO) NOT NULL
- **DT_EMISSAO**: DATE NOT NULL
- **CD_AUTENTICIDADE**: VARCHAR(60) NOT NULL (UNIQUE)

### TB_REGISTRO_FEEDBACK (Feedback)
- **ID_FEEDBACK**: INT (PK)
- **ID_INSCRICAO**: INT (FK -> RL_INSCRICAO_HISTORICO.ID_INSCRICAO) NOT NULL
- **VL_NOTA_SATISFACAO**: INT NOT NULL (CHECK: 1 to 5)
- **DS_COMENTARIO_ABERTO**: TEXT

### RL_INSCRICAO_HISTORICO (Enrollment History)
- **ID_INSCRICAO**: INT (PK)
- **ID_PARTICIPANTE**: INT (FK -> TB_PARTICIPANTE.ID_PARTICIPANTE) NOT NULL
- **ID_ATIVIDADE**: INT (FK -> TB_ATIVIDADE.ID_ATIVIDADE) NOT NULL
- **ST_PRESENCA**: VARCHAR(20) NOT NULL
- **VL_NOTA_AVALIACAO**: DECIMAL(4,2) NULL

### RL_ALOCACAO_INSTRUTOR (Instructor Allocation)
- **ID_ATIVIDADE**: INT (FK -> TB_ATIVIDADE.ID_ATIVIDADE) (PK Part 1)
- **ID_INSTRUTOR**: INT (FK -> TB_INSTRUTOR.ID_INSTRUTOR) (PK Part 2)
- **VL_CARGA_HORARIA**: INT NOT NULL

### RL_PATROCINIO_EVENTO (Event Sponsorship)
- **ID_PARCEIRO**: INT (FK -> TB_PARCEIRO.ID_PARCEIRO) (PK Part 1)
- **ID_ATIVIDADE**: INT (FK -> TB_ATIVIDADE.ID_ATIVIDADE) (PK Part 2)
- **VL_APORTE**: DECIMAL(12,2)

### RL_MEMBRO_PROJETO (Project Membership)
- **ID_PARTICIPANTE**: INT (FK -> TB_PARTICIPANTE.ID_PARTICIPANTE) (PK Part 1)
- **ID_PROJETO**: INT (FK -> TB_PROJETO_EXTENSAO.ID_PROJETO) (PK Part 2)
- **TP_PAPEL_ATUACAO**: VARCHAR(30) NOT NULL
